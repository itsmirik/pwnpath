# RSA: Общий делитель

Были перехвачены два отдельных RSA-сообщения. У каждого свой модуль
(`n1`, `n2`), экспонента и шифртекст - всё это в файле `rsa.txt`.

По отдельности каждый 2048-битный модуль факторизовать невозможно. Но два ключа
были сгенерированы небрежно - в этом и суть задания. Расшифруйте любое из
сообщений, чтобы получить флаг.

Формат флага: `byuctf{...}`

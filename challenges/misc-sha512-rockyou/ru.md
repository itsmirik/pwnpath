# SHA-512

Нам удалось раздобыть ещё один хеш пароля, и мы почти уверены, что открытый
текст есть в классическом списке `rockyou.txt`.

Хеш (`hash.txt`) - это SHA-512:

```
236F5D6EA7C7A931B2D9C3D795F7EA1A6A943A62FCB141B02B5F016A98FA7A9BB305CA72FD880BA1BF9278DB0234FB063754BA560B9299B34A6DDCDF87F2039C
```

Восстановите пароль.

Формат флага: `ctf{password}`

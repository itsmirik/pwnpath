# Одноразовый блокнот

> Я только что узнал об алгоритме шифрования, который невозможно взломать,
> поэтому дам тебе шифртекст - уверен, ты его не взломаешь. Я настолько
> уверен, что даже скажу: в качестве секретного ключа я использовал свой пароль!

Шифртекст:

```
SKWDHAICUG
```

Шифр комбинирует каждую букву открытого текста с буквой ключа (классический сдвиг
в стиле одноразового блокнота по алфавиту A-Z). Восстановите открытый текст.

Формат флага: `byuctf{ANENGLSHPHRSE}`

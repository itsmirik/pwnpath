# Секрет автовхода

Мне надоело вводить пароль каждый раз, поэтому я включил автоматический вход на своём Mac. Но ничего страшного, ведь операционная система наверняка хранит мой пароль надёжно...

Вы восстановили файл, в котором macOS хранит этот пароль для автоматического входа. Восстановите исходный пароль, чтобы получить флаг.

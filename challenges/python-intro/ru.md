Небольшой скрипт на Python просит ввести флаг и печатает `Success!` только при правильном вводе.

Флаг не хранится в виде текста. Вместо этого в скрипте есть список чисел, и над каждым введённым символом выполняется небольшое арифметическое действие перед сравнением. Прочитайте код, поймите преобразование и обратите его, чтобы восстановить флаг.

Вам дан файл: `pythonintro.py`.
